# Conocimiento de Barber Studio

Las skills del proyecto se mantienen en `skills/`. Leer solo la relevante a la tarea; contrastar el conocimiento con los archivos actuales antes de editar.

- `skills/barber-frontend/SKILL.md`: estructura de la landing, identidad visual, contenido, responsive y accesibilidad.
- `skills/barber-booking/SKILL.md`: contrato del formulario, simulación y transición a reservas reales.
- `skills/barber-release/SKILL.md`: servidor, verificaciones, build y GitHub Pages.

El sitio usa HTML/CSS/JavaScript nativos. La marca y los datos comerciales son provisionales; el formulario actual no crea reservas. Para contexto comercial y recursos, consultar `README.md`.

- Para preparar una segunda propuesta independiente (por ejemplo Barber_2), leer primero skills/barber-second-concept/SKILL.md: contexto compartido, datos pendientes, separación de Git y publicación propia en Cloudflare.
