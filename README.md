# The Pip's Barber — Concepto B

Segunda propuesta independiente, inspirada en https://www.fabthebarber.co.uk/.
Repositorio: https://github.com/Dariobod/Barber_2.
Carpeta: C:\codex\Barber_2. La alternativa A permanece en su carpeta y proyecto originales.

HTML, CSS y JavaScript nativos, sin dependencias. Node >=20.

- npm run dev: servidor local.
- npm run check: recursos, IDs, anclas y sintaxis.
- npm run build: genera dist con los cinco videos y portadas.

Cloudflare Pages: proyecto independiente para B, rama main, preset None,
comando npm run check && npm run build, salida dist, NODE_VERSION=22.

Servicios: Corte de adultos y Corte de Barba con Pipa, 40 minutos.
Lunes a viernes, 10 a 18 (Buenos Aires). Tarifas a consultar; dirección pendiente.
Agenda integrada: https://barberpips.setmore.com/. Las confirmaciones las gestiona la agenda.
Los cinco videos son de Pipa. Las fotografías de concepto no representan el local real.
